# 🚆 RailLTL

**AI 기반 소량 화물(LTL) 철도 결합 운송 통합 플랫폼**

트럭으로만 다니던 소량 화물을 철도 화물역(CY) 경유 door-to-door 운송으로 전환해, 비용과 탄소 배출을 동시에 줄이는 걸 목표로 하는 서비스입니다. 화주 견적부터 화주 추적, 트럭기사 배차, 코레일 관제·화차배치까지 화물 하나의 전 여정을 하나의 플랫폼에서 다룹니다.

화물역 7곳(오봉·의왕·부산항(신항)·부산진·천안·순천·포항)을 기준으로 동작합니다.

---

## 누가 무엇을 하는 서비스인가

| 대상 | 화면 | 하는 일 |
|---|---|---|
| 🚚 화주 | 견적 생성 | 트럭 단독 vs 트럭+철도 통합운송 요금·시간·탄소배출량 비교, 예약 확정 |
| 📦 화주 | 실시간 추적 | 예약한 화물의 door-to-door 진행 단계·지연위험도·탄소 마일리지 확인 |
| 🚛 트럭기사 | 화물 매칭 | 오늘 도착 예정 화물, 복귀길에 실을 수 있는 화물 추천, 예상 수익 |
| 🛰️ 코레일 | 관제센터 | 전체 예약 현황, 운송 단계별 집계, 화물역별 물동량, 발행 탄소마일리지 |
| 🚃 코레일 | 화차 배치 | 예약 건마다 어느 화차에 실을지 AI가 추천 |

## 1. 화주 — 견적 생성

- **트럭 단독 vs 트럭+철도 통합운송** 비교: 요금, 이동거리, 소요시간, CO₂ 배출량을 카드 두 장으로 나란히 제시
- **AI 자유입력**: "서울 송파구청에서 부산 광안리해수욕장으로 폭죽 5톤 내일모레 아침에 보내야 해요" 한 문장을 치면 출발지·도착지·화물종류·중량·희망일시를 자동으로 채움. 이때 출발지·도착지는 지오코딩을 거쳐 정확한 주소로 정규화됨
- **화물종류 AI 분류**: 화물종류를 자유 텍스트로 입력하면 일반화물/냉장·냉동/위험물/파손주의·고가품/농산물·생물 5개 카테고리 중 하나로 AI가 판단(사전에 없는 표현도 의미 기반으로 처리)해 요금 할증·수단 제한에 반영
- **실제 열차시각표 반영**: 코레일 화물열차 운행계획 데이터를 기준으로, 직행 열차가 있으면 그 시각표를, 없으면 평균속도 기반 추정 시각을 사용
- **탄소 마일리지 적립 미리보기**: 철도 이용 시 절감되는 탄소량을 마일리지 포인트로 환산해 예약 전에 미리 보여줌
- **이동경로 지도**: 트럭 직송 경로와, 철도 이용 시 첫마일(트럭)-철도구간-막판마일(트럭) 경로를 지도로 시각화
- **AI 상담 챗봇**: 지금 조회한 견적 내용(요금, 소요시간, 할증률 등 서비스가 실제로 쓰는 요금 산정 규칙 포함)을 근거로 "철도가 왜 더 저렴해?", "위험물이면 요금이 어떻게 바뀌어?" 같은 질문에 답변
- **과거 시각 입력 방지**: 희망 출발시각이 현재보다 과거면 확인을 한 번 거침
- 500kg 이상이면 다른 화주와의 결합 여부와 무관하게 철도 이용 가능

## 2. 화주 — 실시간 추적

- 예약 확정된 화물의 door-to-door 진행 단계를 8단계로 표시 (화주 공장 출발 → 첫마일 → 화물역 도착 → 철도 상차대기 → 철도 운송중 → 도착 화물역 → 막판마일 → 최종 도착)
- **AI 지연위험도**: 실측 요일별 운휴율 통계 기반으로 학습된 예측 모델이 지연 확률을 계산하고, 그 옆에 AI가 "어떤 요인 때문인지" 사람이 이해할 수 있는 문장으로 설명 (전문용어·숫자 노출 없이)
- **기상청 실시간 예보 반영**: 출발 시점의 실제 날씨(단기/중기예보)를 조회해 지연위험도 설명에 참고 신호로 반영
- 이동경로 지도, 건별 탄소 마일리지·탄소 절감량 표시

## 3. 트럭기사 — 화물 매칭

- GPS 기준 현재 위치의 화물역에 도착 예정인 화물 목록
- **복귀 화물 매칭**: 화물을 내려준 뒤 빈 차로 돌아가지 않도록, 현재 위치에서 실을 수 있는 복귀 화물을 추천하고 적합도 점수·예상 수익을 함께 제시
- AI가 왜 이 화물이 적합한지 자연어로 설명

## 4. 코레일 — 관제센터

- 전체 예약 건수, 운송 진행 중 건수, 결합배송 비율, 화차 배정 완료율 한눈에
- 탄소절감 합계(kgCO₂eq)와 **발행 탄소마일리지**(화주에게 지급해야 할 포인트 총량, 재무 관점 지표)를 함께 표시
- 운송 단계별 현황, 화물역별 예약 집중도
- 개별 화물 검색·필터

## 5. 코레일 — 화차 배치

- 예약 확정됐지만 아직 화차가 배정되지 않은 화물마다, 학습된 예측 모델이 편성 내 화차 Top 5를 적합도 순으로 추천
- 화물 규격(길이·폭·높이)은 화주가 직접 입력하지 않는 값이라, 중량과 화물종류(카테고리별 평균 밀도)로 자동 추정
- **위험물 안전 규칙**: 액체·기체 위험물은 탱크차만 후보로, 그 외(일반·고체위험물)는 탱크차 자체를 후보에서 제외 — 모델 점수보다 이 규칙이 항상 우선
- 편성 화차 수를 관제센터 담당자가 직접 조정 가능
- 추천 카드에서 바로 배정 확정

## 공통 — AI가 쓰이는 곳

| 기능 | 무엇을 하는가 |
|---|---|
| 자유입력 파싱 | 문장 → 출발지/도착지/화물종류/중량/일시 구조화 |
| 주소 정규화 | 지명·랜드마크 → 정확한 지오코딩 주소 |
| 화물종류 분류 | 자유 텍스트 → 5개 카테고리 |
| 지연위험도 설명 | 예측 확률 + 실시간 날씨 → 사람이 읽을 문장 |
| 복귀화물 매칭 설명 | 적합도 점수의 근거를 트럭기사에게 설명 |
| 상담 챗봇 | 현재 견적 컨텍스트 기반 멀티턴 대화 |

숫자·확률 계산은 전부 결정론적 코드 또는 학습된 예측 모델이 담당하고, AI(Gemini)는 자연어 파싱과 설명 생성만 맡습니다 — 계산 결과 자체를 AI가 새로 만들어내지 않습니다.

## 기술 스택

- **프레임워크**: Streamlit (멀티페이지, `st.navigation`)
- **AI**: Google Gemini (자연어 파싱·분류·설명), LightGBM(지연위험도 예측, 화차 배치 추천 — 두 모델 모두 실측 통계 기반 데이터로 학습)
- **지도**: pydeck
- **외부 API**: Google Geocoding, 카카오모빌리티 길찾기, 기상청 API Hub(단기/중기예보)
- 외부 API 키가 없어도 앱이 죽지 않고 추정치로 자동 폴백합니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

`.streamlit/secrets.toml`에 아래 키를 등록하면 실제 API 기반으로 동작합니다.

```toml
KAKAO_REST_API_KEY = "..."
GOOGLE_MAPS_API_KEY = "..."
GEMINI_API_KEY = "..."
KMA_AUTH_KEY = "..."
```
